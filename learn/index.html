// self-paced deep dives beginner → advanced, one module at a time

Pick a module. Go deep.

The crash courses are the weekend sprint — refreshers for things you basically know. This track is the slow cooker: full tutorials that assume nothing, build from first principles, and end at interview-grade depth. Plain language, quizzes that keep you honest, and code you run right on the page.

Every module stands alone. Start anywhere, in any order, whenever you want — progress saves per module, in your browser. And yes, the examples feature a recurring cast of cats. Learning sticks better when Mochi is involved. 🐈‍⬛
